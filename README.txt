# Daily Light Exposure Data Analyzer

## 1. Project Overview
The Daily Light Exposure Data Analyzer is a Python-based project designed to analyze light exposure measurements using sample CSV data.

It calculates overall and daily statistics and generates a graphical representation of daily average light exposure.

## 2. Technologies Used
- Python 3
- CSV Module
- Matplotlib
- Collections Module

## 3. Project Features
- Reads light exposure data from a CSV file.
- Calculates total records.
- Calculates average light exposure.
- Identifies highest and lowest exposure levels.
- Performs date-wise statistical analysis.
- Generates a daily average exposure graph.
- Exports results into a CSV analysis report.

## 4. Project Files
- light_analyzer.py: Main Python program.
- light_data.csv: Sample dataset.
- analysis_report.csv: Generated analysis report.
- light_exposure_graph.png: Generated graph.
- README.txt: Project documentation.

## 5. How to Run
1. Install Python.
2. Install Matplotlib using: pip install matplotlib
3. Open the project folder in VS Code.
4. Run light_analyzer.py.

## 6. Data Note
This project uses simulated sample data for educational and demonstration purposes. It does not contain real human participant measurements.

## 7. Project Objective
The objective is to practice Python programming, CSV data handling, statistical calculations, and data visualization.
